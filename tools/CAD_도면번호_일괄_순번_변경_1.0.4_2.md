## 작동 원리

이 도구는 “첫 도면에서 기준을 잡고, 같은 기준을 모든 도면에 반복 적용”하는 방식으로 동작합니다.

1. DWG 파일 목록을 사용자가 정한 순서 그대로 처리합니다.
2. 첫 DWG에서 도곽 후보 블록을 찾고, 사용자가 기준 도곽을 고릅니다. 자동 후보가 애매하면 첫 DWG에서 직접 선택할 수 있습니다.
3. 기준 도곽 안에서 `기준 검색 문자`를 포함한 Text/MText를 찾아 도곽 기준 상대 위치를 저장합니다.
4. 나머지 도곽에서는 같은 상대 위치의 Text/MText만 도면번호 후보로 인정합니다. 상대 위치 허용 오차는 내부 고정값 5를 사용합니다.
5. 각 파일 안의 도곽은 좌상단에서 우하단 방향으로 정렬하고, 파일 목록 순서대로 이어서 번호를 배정합니다. 증가값은 항상 1입니다.
6. `분석 미리보기`는 원본 DWG를 저장하지 않고 파일별 도곽 수, 번호 범위, 변경 전후 값을 계산합니다.
7. `원본에 적용`은 미리보기 이후에만 활성화되며, 최종 확인 뒤 원본 DWG에 저장합니다.

## 화면 구성

- `DWG 파일 목록`: 처리할 파일을 추가합니다. 각 행은 미리보기 전에는 `미분석`, 미리보기 후에는 도곽 수와 번호 범위를 보여줍니다.
- `인식 기준`: 첫 DWG에서 기준 도곽과 기준 도면번호 문자를 찾는 데 필요한 값만 받습니다.
- `번호 규칙`: 접두어, 시작 번호, 자리수만 사용자가 정합니다.
- `분석 미리보기`: 원본 저장 없이 변경 계획을 보여줍니다.
- `원본에 적용`: 미리보기 결과 확인 후 실제 저장을 수행합니다.

## 고정 규칙

- 파일 처리 순서: 화면의 파일 목록 순서
- 도곽 처리 순서: 파일 내부 좌상단에서 우하단
- 번호 증가값: 1
- 검색 대상 문자: Text, MText
- 상대 위치 허용 오차: 5
- 백업 정책: 별도 백업 없음, 원본 직접 수정 전 최종 확인

## 중단 조건

- CAD MCP 서버가 연결되지 않은 경우
- DWG 파일이 선택되지 않은 경우
- 첫 DWG에서 기준 도곽을 확정하지 못한 경우
- 기준 도곽 안에서 기준 검색 문자를 포함한 Text/MText를 찾지 못한 경우
- 다른 도곽에서 같은 상대 위치의 Text/MText가 없거나 여러 개라서 확정할 수 없는 경우
- 미리보기 없이 원본 적용을 시도한 경우
