1차로 만들 범위 선택

Codex/Claude와 CAD/Revit MCP 연결을 저장하고 실행하는 프로그램을 어떤 단위부터 만들지 고르는 단계입니다.

A

MCP 연결 저장소 먼저

CAD/Revit별 MCP 서버 정보, 포트, 실행 명령, 상태를 저장하고 불러오는 로컬 관리 앱부터 만듭니다.

B

Codex/Claude 연결 허브 먼저

Codex와 Claude가 각각 어떤 포트와 MCP 서버를 쓰는지 감지/등록하고, 선택한 대상에 연결하는 허브를 먼저 만듭니다.

C

CAD/Revit 브리지 먼저

AutoCAD와 Revit 쪽 플러그인 또는 브리지 프로세스부터 만들고, 나중에 관리 앱과 Codex/Claude 연결을 얹습니다.
